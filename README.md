# MatchDay Ultimate v1.3

Football and cricket scores in a Capacitor Android application.

Features: local match search, favorite-team priority, compact cards, dark/light themes, saved-score cache and preference export.

## Android APK

GitHub Actions → Build MatchDay APK → latest successful run → download `MatchDay-v1.3-debug-apk`.

The GitHub build generates its own branded icon assets using `generate_assets.py`. The downloadable ZIP in the ChatGPT conversation contains the original supplied PNG assets. No live score source is guaranteed to remain accessible; unavailable data is never replaced with fabricated scores.
